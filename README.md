# 1. Define the Problem Statement: 
## The goal of this project is to assess the determinants of the effectiveness of foreign aid projects.  Foreign aid is genrally define as funding from governments and international organizations (e.g., the United Nations) intended to improve the livelihoods of disadvantaged people in poorer (less developed) countries.  Billions are spent on foreign aid programs and the potential benefits for beneficiaries are huge.  However, the widely different socio-economic environments in which these programs are administered, the wide variety of program types (e.g., different sectors such as education and health, implementation modalities, project budgets, and reporting requirements), and different ways of measuring effectiveness make assessing project "success" very challenging.  The challenges are related to the number of factors that can impact a foreign aid project and the the subjective nature of success metrics.

## This project is a small contribution to an extensive body of research intended to help make these programs more worthwhile for the communities they aim to assist and the organizations and governments that fund and manage these projects.  There are very few studies that have used Machine Learning techniques to examine foreign aid data so a secondary aim of this project is to introduce these techniques into the ongoing discussion about foreign aid.  That is especially timely not only because of the current hype associated with AI but also because recent policy changes (especially by the American federal government) have put far greater scrutiny on how foreign aid funds are used.

# 2. Model Outcomes or Predictions: 
## This project uses regression as its primary learning method.  That choice is based on a belief that effectiveness is best measured on a continuum, though there could be merit in using classification models where effectivenss measures are distinct categories such as "Poor" "Moderate" and "Highly" effective.  Data availabikuty (see below) also influenced the choice to use regression algorithms.  
## The expected output of the models will be a determination about what models provide the most accurate and robust predictions, as well an assessment of what factors best predict variance in the effectiveness of foreign aid projects.  The models will use supervised learning.  There is an extensive amount of information available about foreign aid projects (project evaluations, journal articles, reports, etc.).  However, my understanding is that a good amount of that information is not included in major LLMs due to access restrictions.  Given the time available for this project and my current ML skill set, unsupervised data would be an extremely intensive undertaking.

# 3. Data Acquisition
## The data are from a scholarly journal article “When Does Transparency Improve Institutional Performance? Evidence from 20,000 Projects in 183 Countries”, published in the American Journal of Political Science in 2021.  The data are publicly [available here](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi%3A10.7910%2FDVN%2FJQGLHX&version=&q=&fileAccess=&fileTag=&fileSortField=&fileSortOrder=&tagPresort=true&folderPresort=true) and used with the permission of the article's lead author Professor Dan Honig.  Though the study uses a single dataset, the data come from a range of sources such as the World Bank, various international foreign aid donor organizations, and others.  The data are also the most complete dataset I could identify that contains a reliable measure of project effectiveness in addition to a range of other features with potential impacts on project effectiveness.  The plot showing that the target feature is continuous is ![here](https://path-to-image.png](https://github.com/AnakStern/A-Michael-Stern-Berkeley-AI-ML-course-Final-Capstone-Project/blob/main/target_histogram.jpg).  Though there are other datasets with information about foreign aid projects, major disparities across data file structures and data collection methods make merging different datasets highly laborious.  Therefore, this work will rely on the single dataset identified above. 

# 4. Data Preprocessing/Preparation: 
## In sum, feature engineering involved a combination of excluding certain features, ensuring features of interest were not categorical (for use with regression models), and dropping missing values and values that would make interpreting the results difficult.
## The dataset contained variables that the academic researchers had previously engineered.  Some of those variables were dropped because they heavily overlapped with information in other features or were encoded as lagged variables which were beyond the scope of the current analysis.  The target feature needed no changes other than dropping null values; it had been standardized to account for variations in the metrics used by various foreign aid donors to measure project effectiveness.   Two potentially important categorical features with information about the foreign aid donors and the sectors of the foreign aid projects (e.g., agriculture, education, health, etc.) were converted to dummy variables.
The training-test split kept the test set at 20 percent of the total data, using the usual Scikitlearn train-test-split function.

# 5. Modeling: 
## I used a simple linear regression model as a baseline.  For more complex analysis, I chose a Random Forest Regressor algorithm and a Ridge regression algorithm.  For both the Random Forests and Ridge models, I used GridSearch CV to find optimal hyperparameters.  I used Mean Absolute Error as a accuracy measure to be consistent across the two types of algorithms and to have a measure of accuracy that would be easier to interpret.  I also generated the Out-of-Bag score for the Random Forests model.


Model Evaluation: 
## The baseline linear regression model generated a very low Mean Squared Error, suggesting that the model was quite accurate.  However, the coefficient values were all quite low, indicating that the features have little predictive power for the target variable (the effectiveness rating for each foreign aid project).  This aligns with the ![correlation matrix heatmap](https://github.com/AnakStern/A-Michael-Stern-Berkeley-AI-ML-course-Final-Capstone-Project/blob/main/correlation_heatmap.jpg) generated during exploratory data analysis which found no strong correlations between the target and any other feature.
## The Out-of-Bag score for the accuracy of the Random Forests Regressor was very high (0.98) and the Mean Absolute Error for the same model (after using the optimized hyperparameters) was very low for both the training and test datasets (0.001).  These suggest a very high degree of accuracy of the Random Forests model and raised the question whether the model was overfitting.  However, the low MAE for the test set and the low probability of "data leakage" (i.e., there is not a feature in the X dataframe that is measuring the something very similar to the target in the y dataframe) seems to make overfitting unlikely.  However, like the linear regression baseline model, the Random Forest results show that none of the features explain any significant amount of variance of the target.
## Ridge regression (with optimized alpha hyperparameter) results were generally similar to the Random Forest algorithm: very low Mean Abolute Error but coefficients that showed very low impact on the variance of the target (project effectiveness).  From a theoretical perspective, the features that had the largest impact made sense: i) having a way to submit an appeal to a donor about a project would increase donor accountability to produce good results; ii) stronger rule of law would contribute to greater donor accountability to produce good results and perhaps limit corruption; and iii) having a Freedom of Information law to enable people to seek information about a project from a donor.  Yet all these impacts remained quite small on project effectiveness.  A test of Mean Absolute Error using cross-validation produced a very low error as well.
## The overall conclusion is that the features in the dataset are not good predictors of foreign aid project effectiveness.  That points towards future analysis using other features not included in the dataset, a direction that would require acquiring additional data.  Another possiblity is to seek other measures of project effectiveness.  The metric used is a standardized combination of various project rating scales used by different donors.  This mixed measure and the subjectivity associated with project ratings (in some cases, the donors themselves rate their own projects which could introduce substantial measurement bias) probably leaves room for an improved target metric.
